# Демонстрация SYNC

Используйте два устройства с одним адресом приложения через Caddy
либо обычное и приватное окно на localhost:3000.

1. Откройте главную и создайте комнату одним нажатием.
2. Выберите трек, покажите приглашение и QR.
3. Во второй сессии откройте приглашение, введите имя и войдите.
4. На обоих устройствах нажмите «Включить звук / Готов слушать».
5. HOST нажимает Play. Проверьте звук на обоих устройствах.
6. Поставьте паузу со второго устройства; HOST перематывает и продолжает.
7. Отправьте реакцию, добавьте композицию в очередь, загрузите свою запись.
8. Перезагрузите страницу второго слушателя: сессия и актуальное состояние
   восстанавливаются; звук нужно снова разрешить жестом.
9. Покажите /sync-lab: RTT, оценку часов, позицию и коррекцию drift.

Для объяснения жюри: сервер хранит единственное состояние комнаты,
Socket.IO доставляет команды, аудио идёт по HTTP Range. Каждый браузер
вычисляет позицию по серверным часам и корректирует свой плеер.
Диагностика временной позиции не измеряет акустическую задержку устройства.

Перед показом на телефоне проверьте настоящий звук, фоновые ограничения
и доступность адреса из сети телефона. Настройка: [DEPLOY.md](../DEPLOY.md).
