# Музыкальные провайдеры и «Звук»

Рабочий основной режим SYNC — локальная музыка: каталог и приватные загрузки комнаты.
LocalMusicProvider получает данные из этих источников.

Контракт MusicProvider находится в packages/shared/src/music-provider.ts.
Он описывает поиск, метаданные, библиотеку, плейлисты и разрешение воспроизведения.
Backend-реализации находятся в apps/server/src/providers.

Live API «Звука» не подключён. ZvukMusicProvider возвращает UNSUPPORTED
для недоступных операций; интерфейс может открыть официальную страницу трека.
Это не синхронное воспроизведение подписной музыки.

Будущий разрешённый metadata adapter проверяется mock-тестами. Их успех
не подтверждает работу внешнего сервиса. Токены сервисов и скачивание
подписного аудио не являются частью реализации.
