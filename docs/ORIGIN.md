# Происхождение реализации

Основной проект: [Sake14/SYNC](https://github.com/Sake14/SYNC), ветка main.

SYNC начат как самостоятельный учебный monorepo. Базовые HTTP-маршруты,
хранилище метаданных и общий пакет последовательно написаны и проверены
в этом репозитории. Из-за срока хакатона разработчик затем разрешил перенос
своей реализации [Sake14/hakaton_MVP](https://github.com/Sake14/hakaton_MVP)
с объяснением устройства и сохранением происхождения кода.

Эталон переноса: коммит
[83c42968d41af542b14489558c2b1a9e10ea0d75](https://github.com/Sake14/hakaton_MVP/commit/83c42968d41af542b14489558c2b1a9e10ea0d75).
Backend переносился разработчиком по модулям. Завершение frontend,
браузерных тестов и инфраструктуры поручено Codex 2026-10-16.

Сохранены внешний вид, маршруты, протокол v4 и поведение плеера эталона,
включая native-профиль Apple. Пакеты адаптированы к @sync/shared,
@sync/server и web; инфраструктура, CI и документация относятся к SYNC.
Старые серверные адреса, release-теги и результаты проверок резервного проекта
не являются результатами этого репозитория.

Зависимости сохраняют собственные лицензии; список из package-lock.json:
[THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).
Демотреки генерирует локальный скрипт без скачивания чужой музыки.
